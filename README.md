## Hey, I’m Hafiz

I’m a developer from Malaysia who enjoys taking an idea from a rough sketch to something people can actually use. My background is in statistics, so I care about clear thinking, reproducible work, and turning data into useful stories.

These days I’m building desktop and web experiences, improving my software architecture, and making tools that are useful to Malaysian students and communities. I also still love the Minecraft plugin work that got me into programming in the first place.

## What I’m working on

- [**Budu**](https://github.com/hafiz122/budu): an open-source macOS launcher for playing Windows Steam games on Apple Silicon.
- [**aremath.com**](https://aremath.com): interactive learning tools for Malaysian SPM Additional Mathematics students.
- Better data storytelling, time-series forecasting, and maintainable software design.
